# 🏦 Bank Transaction Analytics | Power BI

An interactive **Power BI dashboard** for analyzing banking transactions, customer behavior, transaction channels, locations, account balances, and transaction trends.

Built using **Power BI, DAX, Power Query, and data modeling**, the project transforms raw transaction data into **clear business insights through interactive KPIs, visual analytics, and dynamic filters**.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `Bank_Transaction_Analytics.pbix` in **Power BI Desktop**.
3. Update the dataset path if required.
4. Refresh the data.
5. Explore the dashboard using the slicers and navigation buttons.
